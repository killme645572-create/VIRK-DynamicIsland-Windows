# Island (MVP)

Dynamic Island для Windows 10/11 на C# + WPF (.NET 10).

## Запуск
1. Установить .NET 10 SDK: https://dotnet.microsoft.com/download
2. В папке проекта: `dotnet run`
3. Сборка в exe: `dotnet publish -c Release -r win-x64 --self-contained false`

## Установщик (самый удобный способ передать)
1. Положи `ffmpeg.exe` рядом с `Island.csproj` (для записи экрана) и поставь Inno Setup 6: https://jrsoftware.org/isdl.php
2. Запусти `build-installer.bat`: он соберёт программу и положит `Island-Setup-<версия>.exe` в папку `installer-output`.
3. Отправь этот один файл. Он ставится для текущего пользователя без прав администратора, умеет создать ярлык и включить автозапуск, а при удалении оставляет настройки в `%AppData%\Island`. Версия меняется в `installer\Island.iss` (`AppVersion`).

Первый запуск у нового человека: остров сам откроет окно для ключа ИИ, а ненастроенные плитки VPN и ленты скроет. Вернуть их можно во вкладке ⚙ → «Плитки в «Управлении»».

## Передать другому человеку
1. Скачай `ffmpeg.exe` (https://www.gyan.dev/ffmpeg/builds/ → release essentials, файл лежит в `bin\`) и положи рядом с `Island.csproj` (для записи экрана; без него остальное работает).
2. Собери версию, которой не нужен установленный .NET: `dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true`
3. Папка `bin\Release\net10.0-windows10.0.19041.0\win-x64\publish\` — это готовая программа (`Island.exe` и `ffmpeg.exe` рядом). Заархивируй её в zip и отправь: другому человеку достаточно распаковать и запустить `Island.exe`.
4. ИИ-чат у каждого работает на его собственном бесплатном ключе. При первом запуске (если ключа ещё нет) остров сам открывает окно «Подключи ИИ»: выбрать провайдера (Groq, OpenRouter или Ollama), нажать кнопку, которая открывает страницу ключа, вставить ключ и нажать «Проверить и сохранить». Позже окно можно открыть командой `/key` в чате или кнопкой «🔑 Ключ для ИИ…» во вкладке ⚙. Ключи хранятся только на его ПК, в архив они не попадают.

В сборку входит ffmpeg (https://ffmpeg.org, сборка gyan.dev под GPL).

## Обновления через GitHub
Остров через 12 секунд после запуска и потом раз в 6 часов смотрит последний релиз на GitHub. Если версия новее установленной, он показывает тост «⬆ Доступно обновление …» и сообщение у значка в трее, а в ⚙ появляется зелёная кнопка «⬆ Обновить до …» (открывает загрузку установщика). Проверить вручную: кнопка «🔄 Проверить обновления» в ⚙ или пункт в меню значка в трее.
1. Впиши репозиторий: `Updater.DefaultRepo` в `Updater.cs` (вид `владелец/репозиторий`) или `UpdateRepo` в `settings.json`. Пока там `OWNER/Island`, проверка молчит.
2. Версия программы — `<Version>` в `Island.csproj` (и `AppVersion` в `installer\Island.iss`).
3. Выпуск обновления: подними версию, собери `build-installer.bat`, на GitHub создай Release с тегом выше текущей версии (например `v1.3.0`) и приложи `Island-Setup-1.3.0.exe`. Теги вида `v1.3.0` и `1.3.0` понимаются одинаково; черновики и пре-релизы пропускаются.
4. Отключить проверку: `"UpdateCheck": false` в `settings.json`.

## Что умеет
- Пилюля сверху по центру, всегда поверх окон, не в панели задач
- В покое показывает время и погоду (Open-Meteo). Город определяется один раз по IP (ipwho.is) и сохраняется в `%AppData%\Island\settings.json`; там же можно задать `Lat`/`Lon` вручную или выключить погоду: `"ShowWeather": false`
- Наведи мышь — раскрывается; уберёшь — сворачивается
- Копирование текста — тост «Скопировано: …»
- ✕ в раскрытом острове закрывает приложение
- «Жидкая форма»: нижний край острова волнуется и «капает» сильнее, когда остров раскрыт или звонит таймер
- Персонаж: в покое слева в пилюле глазки — моргают, смотрят вслед курсору, щурятся, пока идёт таймер, а при сигнале таймера широко раскрываются и трясутся
- Статус Claude Code: в пилюле «✦ Claude работает» (или «✦ Claude · N мин»), тост «✋ Claude Code ждёт тебя» и «✓ Claude Code закончил · 2м 14с». Остров слушает `127.0.0.1:47831`, а хуки Claude Code шлют туда события. Подключение: вкладка ⚙, кнопка «🧩 Хуки Claude Code → в буфер», вставить в `~/.claude/settings.json` (если секция `hooks` уже есть — слить вручную), перезапустить Claude Code. Порт меняется параметром `ClaudePort` в `settings.json`
- 25 персонажей на выбор (вкладка ⚙ → «Персонаж», либо `CharacterId` в `settings.json`: classic, round, sleepy, happy, cat, bear, robot, alien, cyclops, triclops, ghost, angry, love, star, cool, nerd, zombie, coffee, fox, bunny, owl, frog, vampire, monster, pixel). Настроения: следит за курсором и моргает; щурится, пока идёт таймер или работает Claude Code; «задумывается» (точки над головой), пока чат ждёт ответ; радуется 8 секунд после «Claude Code закончил»; на сигнале таймера раздувается и трясётся
- Оба эффекта включаются и выключаются во вкладке ⚙ (`Liquid`, `Character` в `settings.json`)
- Вкладки раскрытого острова: «Главная» (плеер и быстрые кнопки), «Погода» (температура, ветер со стрелкой, влажность, давление, прогноз на 6 часов), «⚙» (цвет острова, погода вкл/выкл), «Буфер» (последние 30 копирований, клик — вернуть в буфер; 📌 закрепляет запись наверху списка, закреплённое сохраняется между запусками в `%AppData%\\Island\\pins.bin`, зашифрованное DPAPI, до 50 записей по 5000 знаков, ✕ убирает запись, сверху строка поиска; не закрепляй пароли), «Инструменты»:
  - ✂ Область и 🖥 Весь экран — скриншот в буфер и в `Pictures\Screenshots`
  - После выделения области открывается редактор прямо поверх снимка: ✏ карандаш, ↗ стрелка, ▭ рамка, 6 цветов, ↶ отмена (Ctrl+Z), ✓ или Enter — готово (в буфер и в `Pictures\Screenshots`), Esc — отмена. Отключить: `"EditShots": false`
  - ⏺ Запись экрана — MP4 в `Videos\Island`. Видео пишет `ffmpeg` (кодер NVENC видеокарты NVIDIA, при неудаче — libx264), звук — по кнопке «Звук»: звук ПК / ПК + микрофон / только микрофон / без звука (по умолчанию — только звук ПК, микрофон включается этой кнопкой). Если с звуком что-то не так, остров покажет предупреждение, а подробности лежат в `%AppData%\Island\audio.log`; нужный микрофон можно задать частью названия в `RecMicDevice` (`settings.json`). Во время записи в пилюле идёт время; наведи на остров — во вкладке «Инструменты» кнопка «⏹ Остановить запись». Нужен `ffmpeg.exe` (https://www.gyan.dev/ffmpeg/builds/ → release essentials): положи рядом с `Island.exe`, в `%AppData%\Island` или укажи `FfmpegPath` в `settings.json`. Если звук отстаёт или опережает — подстрой `RecAudioOffsetMs`. Лог ошибок: `%AppData%\Island\ffmpeg.log`
  - 🔤 Текст с экрана — выдели область, распознанный текст (Windows OCR) попадёт в буфер
  - 🎨 Пипетка — клик по любому пикселю копирует цвет `#RRGGBB`
  - 📋 Чистый текст — убирает форматирование у скопированного
  - ▦ QR из буфера — делает QR-код из скопированного текста или ссылки (окно закрывается по Esc или клику)
  - Esc отменяет выделение
- Вкладка «Управление»: плитки Wi-Fi, Bluetooth, Тёмная тема и VPN (включаются одним кликом), кнопки Блокировка / Сон / Перезагрузка / Выключение (перезагрузка и выключение просят второй клик «Точно?»). Стрелка `›` на плитке Wi-Fi открывает список сетей: клик по сети подключает (сохранённые и открытые сразу, для остальных появится поле пароля).
  - 💡 RGB-лента по Bluetooth (контроллеры ELK-BLEDOM, приложение Lotus Lantern): плитка «Лента» включает и выключает, стрелка `›` открывает панель — выбор ленты из найденных Bluetooth-устройств, 10 готовых цветов, радужная полоса для любого цвета, яркость. Выбранная лента и цвет запоминаются (`LedAddress`, `LedName`, `LedColor`, `LedBrightness` в `settings.json`). Яркость самого контроллера остров при включении ставит на максимум (`LedHwBrightness`, по умолчанию 100; если на максимуме лента всё равно тусклая, попробуй 255), а ползунок «Яркость» дальше регулирует цвет. Пока лента подключена к телефону, остров её не увидит — закрой приложение на телефоне. Включи Bluetooth (плитка рядом) до поиска.
  - VPN на другом компьютере: нужен клиент AmneziaWG (или обычный WireGuard, он тоже подходит) и свой файл `.conf`. Нажми плитку VPN (пока профиля нет) или кнопку «🛡 Импорт VPN (.conf)…» во вкладке ⚙: остров подскажет, где взять клиент, и попросит выбрать `.conf`. Файл копируется в `%AppData%\\Island\\vpn`, имя профиля берётся из имени файла. Свой `.conf` в архив с программой не клади: в нём приватный ключ от твоего сервера, и один и тот же конфиг на двух компьютерах одновременно работать не будет. Каждому человеку делай отдельный конфиг (в приложении Amnezia: «Поделиться» → экспорт в формате AmneziaWG).
  - AmneziaWG: если установлен (`C:\Program Files\AmneziaWG`), плитка включает и выключает туннель через `amneziawg.exe`. Нужно указать `VpnName` — точное имя туннеля из окна AmneziaWG. Установка службы туннеля требует прав администратора: при каждом переключении Windows покажет запрос UAC (или запускай остров от имени администратора — тогда без запроса).
  - VPN (другие клиенты): по умолчанию управляет встроенными профилями Windows (`rasdial`), имя профиля — `VpnName` в `settings.json` (стрелка `›` на плитке переключает профиль, если их несколько). Для стороннего клиента задай команды `VpnConnectCmd` / `VpnDisconnectCmd`, а в `VpnName` — имя его сетевого адаптера (по нему определяется статус «Подключён»).
- Плеер: название, исполнитель, пред/пауза/след, прогресс-бар (клик — перемотка), ползунок системной громкости (любой плеер с системным управлением медиа)
- Слова песни: под названием трека показывается текущая строка, синхронно с воспроизведением (база LRCLIB, ключи не нужны; туда уходят только исполнитель, название и длительность трека). Отключить: `"Lyrics": false` в `settings.json`
- Полка (📥): перетащи файлы на остров — он раскроется на вкладке полки, файлы останутся там (список хранится в `%AppData%\Island\shelf.txt`). Потом тащи их из острова в любое окно (копируются, оригиналы не двигаются); «⇪ Перетащить все» уносит всё сразу, двойной клик открывает файл, ✕ убирает с полки.
- Alt+Space открывает и закрывает остров с клавиатуры, Esc закрывает. Выключить: `"Hotkey": false` в `settings.json`
- Быстрые кнопки: Wi-Fi и Bluetooth (открывают настройки), тёмная тема, блокировка
- Чат с ИИ: кнопка «💬 Чат» в раскрытом острове. Сверху два выпадающих списка — провайдер и модель (список моделей подгружается с сервера провайдера; выбор запоминается). Провайдеры: OpenRouter (в списке только бесплатные модели), Groq, Ollama (облако ollama.com по ключу — видеокарта ПК не используется). Ключ вводится в окне «Подключи ИИ» (при первом запуске, команда `/key` без аргументов или кнопка «🔑 Ключ для ИИ…» в ⚙) либо сразу командой `/key провайдер ключ` (например `/key openrouter sk-or-...`; `/key ключ` — для текущего провайдера), хранится зашифрованным через Windows DPAPI. Ключи можно задать и переменными: `OPENROUTER_API_KEY`, `GROQ_API_KEY`, `OLLAMA_API_KEY`. `/model название` — любая своя модель текущего провайдера, `/help` — команды, `/clear` — очистить диалог. Enter — отправить, Shift+Enter — перенос строки, Esc — закрыть список, затем чат
- Картинки в чате: кнопка 📎, Ctrl+V (картинка или файл из буфера, в том числе скриншот острова) или перетаскивание файла на остров, пока открыт чат. До 4 картинок за раз, они уменьшаются до 1280 px и уходят как JPEG. Нужна модель, которая понимает картинки: в списке моделей такие помечены 👁 (у OpenRouter — по каталогу, у Groq и Ollama — по названию, поэтому возможны неточности; у Groq, например, `meta-llama/llama-4-scout-17b-16e-instruct`)
- 🧠 «Спроси про экран»: Ctrl+Alt+Space (или 🛠 → «Спроси про экран») → выдели область → снимок сразу уходит в чат вместе с вопросом, ответ появляется там же. Вопрос по умолчанию — про ошибку, график или иностранный текст; свой задаётся в `AskPrompt` в `settings.json`. Нужна модель с пометкой 👁. Отключить горячую клавишу: `"AskHotkey": false`
- 🎚 Эквалайзер: пока играет музыка, пилюля слегка расширяется и справа в ней пляшут 5 столбиков в такт звуку (NAudio, захват того, что играет в колонках; микрофон не используется). Если звук подключить не удалось, столбики пляшут «для вида». Выключить: вкладка ⚙ или `"Equalizer": false`
- ✨ Умный буфер: скопировал текст — вместо обычного тоста появляются кнопки «Объяснить», «Перевести», «Исправить», «Коротко». Ответ ИИ (провайдер и модель те же, что в чате) приходит прямо в остров; в нём «Копировать» и «В чат» (продолжить разговор). Русский текст переводится на английский, остальной — на `TranslateTo` (по умолчанию «русский»). Кнопки уходят сами через 6 секунд, Esc закрывает. Выключить: вкладка ⚙ или `"SmartClip": false`. Текст уходит провайдеру чата только после нажатия кнопки
- 🍅 Помодоро: «Главная» → «🍅 Фокус». Наборы фокус/перерыв: 25/5, 50/10, 15/3 (большой перерыв — в три раза длиннее обычного, настраивается: `PomoFocus`, `PomoBreak`, `PomoLong`, `PomoRounds` — сколько фокус-сессий в цикле, по умолчанию 4). Фазы идут сами: фокус → перерыв → … → большой перерыв → конец цикла; есть пауза, «Дальше» (пропустить фазу) и «Стоп». В пилюле — «🍅 24:59» или «☕ 04:12». Персонаж на фокусе «работает» (смотрит вниз, бегает глазами по строке), на перерыве радуется, а потом «отдыхает»: глаза прикрыты, дышит, над головой «z»
- ПКМ по острову — «Выход»

- 🎙 Голосовой помощник: запуск тремя способами — горячая клавиша **Ctrl+Alt+V** (держи и говори; быстрое нажатие — говори, остановится по тишине, повторное нажатие заканчивает запись или прерывает ответ), фраза **«Привет, остров»** (кнопка «🗣» в ⚙; распознаётся офлайн средствами Windows, нужен русский речевой пакет: Параметры → Время и язык → Язык и регион → Русский → Параметры → Речь) и кнопка «🎙 Голос» в «Инструментах». Речь переводит в текст Whisper на Groq (нужен ключ Groq: `/key groq gsk_...`). Дальше — либо команда, либо вопрос к ИИ (провайдер и модель те же, что в чате; помощник помнит последние 4 обмена). Команды: «поставь помодоро на 25 минут» / «останови помодоро», «таймер на пять минут» / «отмени таймер», «сделай скриншот» / «скриншот области», «запиши экран» / «останови запись», «что на экране» (выделяешь область → снимок уходит в чат), «включи/выключи ленту», «включи тёмную/светлую тему», «громкость на 30», «громче/тише», «следующий трек», «пауза», «заблокируй компьютер», «открой ютуб» / «открой телеграм» / «открой калькулятор» / «открой загрузки» / «открой youtube.com» (сайты, установленные программы из меню «Пуск», папки), «найди в ютубе котиков» / «загугли …» (поиск), «который час», «какое число», «какая погода». Ответ: текстом, голосом (голоса Windows, нужен русский голос) или и тем и другим — кнопка «Ответ голоса» в ⚙. Выключить всё: «🎙 Голосовой помощник» в ⚙. Что слышит и как распознаёт — в `%AppData%\Island\voice.log`; микрофон выбирается кнопкой «🎤 Микрофон» в ⚙ (`VoiceMicDevice` — часть названия устройства; слово «привет» в режиме Windows (офлайн) всегда слушает микрофон Windows по умолчанию, выбранный работает в режиме Groq); настройки в `settings.json`: `Voice`, `VoiceWake`, `VoiceMicDevice`, `VoiceReply` (text | voice | both), `VoiceLang` (по умолчанию `ru`), `VoiceName` (часть названия голоса Windows).
- 🚀 Мои сайты и программы: вкладка 🚀 в раскрытом острове. «＋ Добавить» — вводишь название (так ты потом зовёшь это голосом) и адрес сайта (`youtube.com`) или путь к программе (кнопка 📁 выбирает файл `.exe` / ярлык). У каждой записи кнопки ▶ открыть, ⏹ закрыть, ✎ изменить, ✕ удалить. Записи хранятся в `settings.json` (`CustomApps`: `Name`, `Target`, `Match`). Голосом: «открой <название>» — свои названия проверяются раньше встроенных.
- ⏹ Закрытие: «закрой ютуб», «закрой калькулятор», «закрой телеграм», «закрой <своё название>», «закрой загрузки», «закрой хром». Программу остров просит закрыться, как крестиком (если спросит «Сохранить?» — ответ за тобой). Если она не закрылась, повтори «закрой» (или ⏹) в течение 20 секунд либо скажи «убей …» / «закрой … принудительно» — тогда процесс завершится сразу. Сайт закрывается как вкладка: остров находит окно браузера, у которого в заголовке есть название сайта (браузер показывает только активную вкладку), переводит его на передний план и жмёт Ctrl+W. Если окно не удалось сделать активным, Ctrl+W не нажимается. Для программ с необычным процессом (или сайтов, чья вкладка называется иначе) в форме есть поле «Как закрывать»: имя процесса (без `.exe`) или слово из заголовка вкладки. Проводник, остров и системные процессы принудительно не завершаются.
- 🗣 Если остров плохо слышит «Привет, остров»: в ⚙ есть две кнопки. «Чувствительность»: строгая → обычная (по умолчанию) → высокая (ловит тихую и неразборчивую речь, фраза «остров» без «привет» тоже срабатывает; ложных срабатываний чуть больше). «Слух»: Windows (офлайн) или Groq (Whisper, понимает по-русски заметно лучше, нужен ключ Groq; короткие фразы до 3,5 с уходят на распознавание, не больше 12 в минуту). Для Windows-режима список фраз расширен («эй, остров», «слушай, остров», «окей, остров») и добавлены «приманки» (похожая обычная речь), чтобы шум не превращался в команду. Что остров слышит и с какой уверенностью — в `%AppData%\\Island\\voice.log`; настройки: `WakeSensitivity` (0–2), `WakeEngine` (`auto` | `groq`).
- 🏷 Имя помощника: теперь он откликается на **«Привет, Вирк»** (а также «эй / слушай / окей / хей, Вирк»; на высокой чувствительности достаточно просто «Вирк»). Имя задаётся в `settings.json`: `AssistantName` (по умолчанию `Вирк`), а `WakeAliases` — другие имена, на которые тоже откликаться (по умолчанию `["остров"]`; пустой список `[]` — только Вирк). Помощник знает своё имя и называет себя так в ответах. После смены имени перезапусти остров. Whisper может записать имя как «Верк» или «Вёрк» — такие варианты тоже засчитываются.
- 🔊 Синхронизация звука записи: в «Инструментах» кнопки «−» и «+» двигают звук на 50 мс (`RecAudioOffsetMs`): звук идёт раньше картинки — жми «+».
